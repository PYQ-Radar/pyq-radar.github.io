How to verify a batch

  1. Prepare only questions whose correct answer has been checked against a reliable answer key or source.
  2. Enter 1–100 records in the JSON box below. Each record needs question_id, correct_option, explanation, source_name and source_url.
  3. Copy the JSON, open the secure GitHub workflow, paste it into records_json, and run the workflow.
  4. Open the workflow run to see which records were verified or rejected.

Never mark an answer verified just because it looks plausible. Missing or uncertain answers must stay unverified. Do not put passwords, API keys, or service-role keys in this page.
